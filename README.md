# Slottica Insights

Аналитический дашборд по поведению пользователей slottica.com: тепловые карты, записи сессий, воронки, пути, сигналы фрустрации, тренды и выводы продуктового дизайна. Собирается из еженедельных выгрузок GA4 (xlsx).

Данные: 26–28.10, 2–4.11, 6–9.11, 11–15.11 и 20–23.11.2026 · slottica.com · бренд Slottica · 52 027 сессий (51 189 без подозрительного трафика), 638 780 событий.

## Разделы

- **Обзор** — KPI с изменением к прошлым выгрузкам, настраиваемые виджеты.
- **Тепловые карты** — клики, rage и повторные клики, глубина скролла по главной, каталогу и акциям (мобайл и десктоп, игрок и гость).
- **Записи сессий** — восстановление сессии по событиям: экран, клики, переходы, сигналы.
- **Воронки** — готовые и свои шаги, сравнение сегментов.
- **Проблемы воронок** — автопоиск узких мест: самый слабый шаг каждой воронки и сегменты (устройство, аудитория, страна, источник, ОС, язык, новизна, выгрузка), которые проходят шаг значимо хуже остальных; разбор ушедших сессий, гипотеза, записи.
- **Пути** — Sankey переходов между страницами.
- **Фрустрация** — rage-клики, U-turn, быстрые выходы из игр, ошибки оплаты и т. д.
- **Тренды** — метрики по дням.
- **Сравнение периодов** — два любых промежутка (A и B): все показатели с z-тестом, дни, воронки, сегменты, что выросло и упало сильнее всего.
- **Выводы** — общие (весь период) и поточные (последняя выгрузка против предыдущих).

Глобальные фильтры: период, устройство, игрок / гость, страна, источник, подозрительный трафик (по умолчанию «Без ботов»). Поиск по разделам, страницам, элементам и играм (Ctrl/⌘ + K), светлая и тёмная тема.

## Обновление данных

Сырые выгрузки (xlsx) и промежуточные файлы в репозиторий не кладутся (`raw/` и `work/` в .gitignore). Скрипты запускаются из корня репозитория, нужны `pandas`, `numpy`, `python-calamine`, `lxml`.

1. Положить выгрузки в `raw/`.
2. `python scripts/load.py` — старые выгрузки (26.10–9.11) → `work/all_raw.pkl`.
3. `python scripts/filter_slottica.py` — только slottica.com и бренд Slottica → `work/sl.pkl`.
4. `python scripts/load_new.py` и `python scripts/map_new.py` — выгрузка 11–15.11 (40 колонок) → добавляется в `work/sl.pkl`.
5. `python scripts/load_23.py` и `python scripts/map_23.py` — выгрузка 20–23.11 (все бренды, лист general, 42 колонки; берётся бренд slottica на slottica.com, scroll_depth сохраняется отдельно) → добавляется в `work/sl.pkl`.
6. `python scripts/build.py` — сессии, сигналы, элементы → `data/sessions.json` и `data/sessions.json.gz`.
7. `python scripts/metrics.py` — сводные метрики для текста выводов → `work/metrics.json`.

Для новой недели копируются `load_23.py` / `map_23.py` с новым именем файла (и файл добавляется в `SESS_SRC` в `build.py`), в `js/core.js` — список неполных дней (`PARTIAL`), в `js/analysis.js` — список выгрузок (`EXPORTS`), в `js/main.js` — пресеты периода и последний день календаря, в `js/findings.js` — тексты выводов.

## Как считаются метрики

- Сессия = `user_pseudo_id` + `session_id`. «Игрок» — если `user_id` есть хотя бы у одного события сессии, иначе «гость».
- Дубли трекинга убраны: одинаковый клик чаще раза в 0,1 с и одинаковый page_view в пределах 1 с.
- Возврат с оплаты — page_view с `?success=true/false`, у которого реферер — платёжный шлюз.
- Rage — 3+ одинаковых клика с паузами ≤ 2,5 с за ≤ 5 с; U-turn — A → B → A, на B ≤ 7 с; быстрый выход из игры — страница игры ≤ 10 с; быстрый уход — 1 страница, 0 кликов, < 10 с.
- Оценка фрустрации 1–5 — взвешенная сумма сигналов.
- Подозрительный трафик — гость на desktop с 5+ сессиями, который видит только главную и делает только отправку формы регистрации (в 20–23.11 — 828 сессий, 7,5% выгрузки). По умолчанию скрыт.
- Проблемы воронок: сегмент сравнивается с остальными сессиями на том же шаге (z-тест, p < 0,05, разрыв от 3 п. п.); потери — насколько сегмент тянет вниз среднюю конверсию шага.

## Ограничения данных

Нет 29.10–1.11, 5.11, 10.11 и 16–19.11; дни 28.10, 4.11, 9.11, 15.11 и 23.11 выгружены не полностью. В 6–9.11 нет событий кассы, модалок, фильтров, акций и турниров. В 11–15.11 у пополнений нет источника открытия кассы, у фильтров не передаётся выбранный провайдер, у 60% сессий источник трафика «(not set)». В 20–23.11 у пополнений по-прежнему нет источника, источник трафика не определён у 55% сессий.
